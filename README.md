**# Cinema Ticket Booking System

A Java-based Cinema Ticket Booking System developed as a KLH Capstone Project using Core Java concepts.

## About the Project

The Cinema Ticket Booking System is a console-based Java application that allows users to view available movies, select seats, and calculate ticket prices.

## Features

- Display available movies.
- Select movies from different categories.
- Display available and booked seats.
- Select seats for booking.
- Calculate ticket prices.
- Confirm or cancel a booking.
- Demonstrate Java String operations and tokenization.

## How to Run

1. Install Java JDK.
2. Download or clone this repository.
3. Open the project folder in VS Code or Command Prompt.
4. Compile the Java file:

```bash
javac CinemaTicketBookingSystem.java
```

5. Run the program:

```bash
java CinemaTicketBookingSystem
```
